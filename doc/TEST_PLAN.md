# OpenMir2 线上运营测试方案

## 一、测试环境准备

### 1.1 服务器要求
- Windows Server 2019+ 或 Linux
- .NET 8.0 Runtime
- MySQL 8.0+
- 内存: 8GB+
- 硬盘: 50GB+

### 1.2 数据库初始化顺序
```bash
# 1. 核心数据库
mysql -u root -p < sql/mir2_account.sql
mysql -u root -p < sql/mir2_data.sql
mysql -u root -p < sql/mir2_db.sql

# 2. 索引优化
mysql -u root -p mir2_db < sql/characters_indexes.sql
mysql -u root -p mir2_db < sql/fix_gamegold_field.sql

# 3. 功能模块
mysql -u root -p mir2_db < sql/shop_system.sql
mysql -u root -p mir2_db < sql/mail_system.sql
mysql -u root -p mir2_db < sql/notice_system.sql
mysql -u root -p mir2_db < sql/activity_system.sql
mysql -u root -p mir2_db < sql/castle_war.sql
mysql -u root -p mir2_db < sql/appraisal_system.sql
mysql -u root -p mir2_db < sql/vip_map_system.sql
mysql -u root -p mir2_db < sql/market_system.sql
mysql -u root -p mir2_db < sql/player_logs.sql
mysql -u root -p mir2_db < sql/gm_admin.sql

# 4. 游戏内容
mysql -u root -p mir2_db < sql/skill_books.sql
mysql -u root -p mir2_db < sql/new_weapons.sql
mysql -u root -p mir2_db < sql/new_armors.sql
mysql -u root -p mir2_db < sql/new_accessories.sql
mysql -u root -p mir2_db < sql/new_monsters.sql
mysql -u root -p mir2_db < sql/vip_map_monsters_config.sql
mysql -u root -p mir2_db < sql/all_weapon_effects.sql
```
