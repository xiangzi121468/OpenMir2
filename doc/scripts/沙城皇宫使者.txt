; 沙城皇宫使者 NPC脚本

[@main]
{
<$CASTLEWAR_ISACTIVE>
#IF
EQUAL <$CASTLEWAR_ISACTIVE> 1
#ACT
GOTO @war_active
#ELSEACT
GOTO @war_normal
}

#SAY

║        沙巴克皇宫使者              ║

║                                    ║
╚════════════════════════════════════╝

<查看城堡信息/@castleinfo>
<报名攻城战/@apply>
<查看报名行会/@viewapply>
<攻城战历史/@history>
{
#IF
CHECKGUILDMASTER
CHECKGUILD <$CASTLEGUILDNAME>
#SAY
<领取税收/@collecttax>   <城堡管理/@manage>
}
<离开/@exit>

#IF
CHECKGUILDMASTER
#ELSEACT
MESSAGEBOX 只有行会会长才能报名攻城战！

#IF
CHECKGUILDMASTER
#SAY
╔════════════════════════════════════╗
║          报名攻城战                ║
╠════════════════════════════════════╣
║                                    ║
║  您的行会: [<$GUILDNAME>]          ║

║  报名截止: 攻城前24小时            ║
║                                    ║
║  下次攻城: <$NEXTWARTIME>          ║
║                                    ║
╚════════════════════════════════════╝

<确认报名/@confirmapply>   <返回/@main>

[@confirmapply]
#IF
CHECKGOLD 1000000
CHECKGUILDMEMBERCOUNT > 9
#ACT
TAKE 金币 1000000
APPLYCASTE 沙巴克
SENDMSG 0 [<$GUILDNAME>] 成功报名沙巴克攻城战！
#SAY
报名成功！

您的行会 [<$GUILDNAME>] 已成功报名沙巴克攻城战。

攻城时间: <$NEXTWARTIME>

请做好准备，祝您旗开得胜！

<返回/@main>
#ELSEACT
MESSAGEBOX 报名失败！请确保：\n1. 金币不少于1,000,000\n2. 行会人数不少于10人
GOTO @main

CHECKGUILDMASTER
